\textbf{Data and code availability.} The source code, the 30-case evaluation

\noindent
\textbf{Ethics.} This work involved no human participants, no personal data and

synthetic.

\vspace{6pt}

\textbf{Use of generative AI.} Large language models are the object of study in
this work and were run as part of the system and its evaluation, as described
throughout the manuscript. Language models were additionally used to assist
with drafting prose and reviewing source code during development. All
quantitative results were produced by executing the described system and are
verified against stored run artefacts; all text has been checked and is the
responsibility of the authors.
