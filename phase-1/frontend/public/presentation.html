GUARDRAILS & BOUNDARY ENFORCEMENT

Deterministic Scope Guard & Zero-Cost Routing

Why 3B local LLMs must not be trusted with negative instructions, and how deterministic guards solve it.

Deterministic Scope Guard (app/agents/scope.py)
• Negative Prompting Fails: Small local models (3B params) suffer from high failure rates when prompted 'do not answer other topics'.
• Signal Scorer Matrix: Evaluates lexical and semantic affinity for current agent vs. all 33 other agent specs.
• Instant Zero-Cost Handoff: If affinity is 0 and another agent scores higher, system immediately triggers a handoff in 0.00s.

CONTINUOUS LEARNING SYSTEM

Semantic Long-Term Memory & Feedback Loop

Vector embeddings with pgvector / portable cosine search, 3 memory scopes, and automatic profile promotion.

3-Tier Memory Isolation
• Agent Scope: Strictly isolated to one agent (e.g. Maths trigonometry tips).
• Domain Scope: Available across all domain agents (e.g. Marketing voice).
• Global Scope: Universal formatting preferences.
Zero cross-domain memory leakage.
2-Strike Promotion Rule
• 1st Correction: User leaves thumbs down with critique → Stored as candidate memory.
• 2nd Repeat: Same preference expressed twice → Promoted to permanent user profile.
• No False Positives: Thumbs down alone does not trigger false adjustments.
Vector Embeddings & Semantic Search
• Powered by nomic-embed-text (768-dimensional vectors).
• Cosine similarity threshold at 0.45 ensures only meaningful matches are recalled.
• Full pgvector index acceleration with SQLite fallback for offline dev.
User Privacy & Full Governance
• Dedicated Settings UI enables users to inspect all stored vector memories.
• Test semantic recall queries live with arbitrary search terms.
• One-click permanent deletion of any memory candidate.

Zero-GPU Branded Images & Analytical Charts

How Zero-GPU Multi-Modal Generation Works

• Matplotlib Analytical Engine: Chart Builder agent plots user-supplied numbers with statistical rigor; refuses to invent fake data.
• Pluggable Cloud Upgrade: Set IMAGE_PROVIDER=openai to switch the same JSON spec to gpt-image-1 for photographic renders.
